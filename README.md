# Bunker-defender
Commodore 64 game
Testing game with real hardware:
Ultimate 64 elite 2 , SID6581 (rev0/1984), Pal 50 hz mode, crt tv screen.
Gameplay ok, but recommended to use joystick, game performance may suffer probably because keyboard polling interrupts active, could be enhanced. Remember to select 'J' at start screen or reload game to select.
